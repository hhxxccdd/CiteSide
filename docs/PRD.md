# ResearchFlow｜技术网页阅读与个人知识助手

> v1.3｜2026-10-19 范围更新。本文是目标，不表示已实现。新一轮设计入口为 SDD-005。当前单篇全文问答已接通，不显示正文预览；@ 多资料、范围开关和流式仍在后续计划中。

## 解决什么问题

阅读技术文章时，直接围绕网页正文提问，结合其他已打开文章和自己的笔记理解问题；必要时允许模型联网找资料。核对回答引用后，把有价值内容编辑成自己的知识笔记。

第一版本地单人使用，一次问题完成一个小闭环，不做多 Agent、复杂记忆、账号同步或完整多轮历史。

## 完整使用流程

1. 打开侧栏，把当前网页正文加入本次资料，不再必须选中文字；权限不足时由用户授权。
2. 输入问题，可通过 @ 添加当前窗口其他已打开网页或个人笔记。
3. 明确是否搜索个人知识库、是否允许联网。默认前者开、后者关；指定笔记始终按 ID 读取。
4. 开始后固定问题和资料。后端按范围检索；允许联网时 Qwen 可自主选择搜索和阅读工具。
5. 回答展示真实来源，悬停引用查看原文片段。切换网页不改变原任务、不清空回答；当前浏览页单独显示。
6. 用户编辑标题和正文，确认保存笔记；以后通过向量检索找回。

## 第一版功能

| 编号 | 功能 | 完成标准 |
| --- | --- | --- |
| F1 | 当前网页正文 | 不选字也可读取；权限、空正文、失败、超长文章有明确提示并阻止提交 |
| F2 | 指定资料 | @ 选择当前窗口网页与笔记；最多 3 篇网页、3 条指定笔记，可移除、去重 |
| F3 | 一次研究任务 | 问题和资料形成固定快照；支持仅网页、仅知识库和组合资料 |
| F4 | 范围与工具 | 知识库和联网独立控制；范围限制在后端真正生效 |
| F5 | 进度与引用 | 流式文字、真实步骤、自然引用文字和来源预览；区分已取得与已引用 |
| F6 | 停止与重试 | 切页继续，主动停止才中断；重试沿用原资料，不串输出 |
| F7 | 编辑保存 | 保存前可编辑、确认，失败保留内容；多来源链接在笔记中保留 |
| F8 | 知识库 | 查看、筛选、修改、删除和向量检索；不自动存入网页或每次回答 |
| F9 | 状态和交付 | 同窗口恢复草稿和最近完成结果；关闭侧栏中断任务，不承诺后台持续执行 |

## 数据与边界

- Vue 3、TypeScript、Chrome MV3；NestJS 持有模型密钥；本机 PostgreSQL + pgvector 保存确认笔记。
- 单篇正文先限 30,000 字符，网页总计 60,000 字符；超限提示并阻止提交，不提供部分正文确认，不静默截取后假称全文。后端另检查上下文预算。
- 只在提交时把选中正文发给后端；打开或切换网页不自动发送，不自动入库。
- 来源必须来自实际资料表，内部编号不展示给用户。搜索结果与已读正文分开，不能把候选都说成已引用。
- 已完成结果保留自己的来源；正在浏览的新页面不会替换旧答案或保存笔记的主要来源。
- 本轮暂缓任意 URL 添加、长文自动分段检索、PDF、视频、知识图谱、跨网站操作、完整历史和云同步。

## 实施顺序

正文读取 → 单篇问答和状态拆分 → @ 多资料 → 多来源保存与恢复 → 流式进度和停止重试。每一步先解释文件分工、再实现并验收。
