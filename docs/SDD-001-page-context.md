# SDD-001：从网页选一段内容，放进研究侧栏

> 2026-10-09 范围调整稿，等你复核。对应 PRD 的 F1、F2。本文件只设计网页选区与人工确认；提问任务见 SDD-002。

## 这一步要做什么

用户打开一篇普通技术网页，点击 ResearchFlow 图标，侧栏显示当前页标题和网址。用户在网页上选中文字后，侧栏自动出现预览。**预览不等于使用**：只有点击“使用这段”，文字才成为下一次提问的内容。

第一版一次只用一段选区，不做多段列表。

## 用户怎样操作

1. 打开侧栏。没有选区时，提示“在网页中选中想研究的内容”。
2. 在网页上选中文字。侧栏显示这段文字和“使用这段”“忽略”按钮。
3. 点击“使用这段”后，侧栏单独显示“本次提问将使用的内容”。此时才可以输入问题并开始任务。
4. 如果继续选了另一段，新文字先作为预览；已经确认的那段仍然保留。再次点击“使用这段”才会替换确认内容。
5. 点击“忽略”只清除新预览，不改变之前已确认的内容。

用户可以清除已确认的内容。清除后，提问按钮变为不可用，直到再次确认一段选区。

## 数据放在哪里

网页读取代码只取得标题、网址和选中文字，再交给扩展后台。侧栏和后台用 Chrome 的会话存储共享两份短期数据：

- **预览：**刚刚选中的文字，尚未被用户同意用于提问。
- **已确认内容：**本次提问真正会用到的一段文字。

两份数据都带标签页 ID 和网址。侧栏显示前要核对它们是否属于当前页。点击“使用这段”只是把预览变为已确认内容，**此时不发给 NestJS**；只有用户点击“开始提问”才发送。

## 特殊情况

- 没选文字时不自动抓取整篇文章。
- 最多保留选区前 8,000 字；截取时在预览里说明。
- Chrome 内部页面等不允许读取时显示“此页面无法读取”，不展示旧页面内容。
- 切换标签页、关闭标签页或当前页跳转后，清空预览和已确认内容。新页面需要重新点击扩展图标。
- 关闭侧栏后重新打开同一页，当前浏览器会话内的已确认内容可以继续使用；浏览器重启或扩展重新加载后不保留。

## 文件怎样分工

    apps/extension/src/
      background/index.ts                 图标点击、标签页变化、暂存选区
      features/page-context/
        watchSelection.ts                 在网页中监听选区
        useSelectionPreview.ts            让 Vue 读取短期数据并跟着变化
        SelectionPreview.vue              预览、确认、忽略与清除界面；实现时再建
      App.vue                              侧栏整体布局

网页读取、状态处理和界面展示各有位置。以后增加“提问任务”时放进单独的 research-run 功能目录，不往选区文件里塞模型调用代码。

## 完成后怎么检查

1. 侧栏打开后选文字，预览会更新；没有确认时不能提问。
2. “使用这段”后可提问；再选新文字不会悄悄替换已确认内容。
3. “忽略”不影响已确认内容；清除已确认内容后不能提问。
4. 换标签页、跳转或遇到不支持的页面时，不会把旧选区当作当前页。
5. 此阶段没有把网页文字发给后端，也没有存进 PostgreSQL。
