# SDD-001：从网页选内容，放进研究侧栏

> 待你审阅的设计稿。对应 PRD 的 F1、F2；现在只写方案，还没有实现。

## 这一步要做什么

你先点击 ResearchFlow 图标，打开侧栏。侧栏显示当前网页的标题和地址。然后你可以继续在网页上选中文字；每次选好，侧栏就显示这段文字的预览。**预览不等于添加**，由你决定要不要把它加入“本次研究”。

侧栏可以一直开着，读到需要的内容时再选。

## 使用过程

1. 打开一篇普通网页，点击扩展图标，侧栏显示网页标题和地址，并提示“在网页中选中想研究的内容”。
2. 你在网页上选中文字，侧栏出现预览，以及“加入本次研究”和“忽略这段”两个按钮。
3. 点击“加入本次研究”，这段文字进入侧栏的“已加入内容”列表；点击“忽略这段”，预览消失，不加入列表。
4. 可以继续选别的文字，重复添加。列表里的每段文字都可以移除。之后提问功能会使用这个列表，但本次先不接提问。

“加入本次研究”只是暂时放在侧栏里，**不会收藏到资料库，也不会发送给后端**。以后做“收藏网页/卡片”时，会提供单独的保存动作，让这两件事不混淆。

## 遇到特殊情况

- 没有选中文字时，侧栏只显示提示，不拿整篇文章来代替。
- 选区很长时，预览只保留前 8,000 个字，并提示已经截取。
- 某些页面（如 `chrome://` 页面）不允许扩展读取。侧栏会说明“此页面无法读取”，不会显示上一页的内容。
- 切换标签页、关闭标签页或当前页跳转后，旧的预览和“已加入内容”都清空。要读新页面，再点击一次扩展图标。这样不会把上一页误当成当前页。
- 关闭侧栏后重新打开同一页，已加入内容可在当前浏览器会话中继续使用；浏览器重启、扩展刷新或切换页面后不会保留。

## 代码怎么分工

前端按功能分目录，不把所有逻辑写在一个 Vue 文件里：

```text
apps/extension/src/
  app/                    侧栏整体布局
  background/             扩展图标、标签页变化、与网页沟通
  features/page-context/  读取选区、暂存内容、预览界面
  shared/                 多个功能都会用到的小工具
```

网页读取和侧栏显示分开：网页侧只负责取得标题、地址和选中文字；侧栏负责预览、加入和移除。短期内容只放在扩展的会话存储中，避免扩展后台休眠时丢失；本阶段不改 NestJS 和 PostgreSQL。后续的资料库、问答、卡片各放在自己的功能目录，新增依赖也写进实际使用它的子项目 `package.json`。

## 做完后怎样检查

- 打开侧栏后再选文字，预览能跟着更新。
- “加入”后内容出现在列表，“忽略”后不会出现；列表内容可移除。
- 换一篇网页、切换标签页、进入无法读取的页面时，不会看到旧内容。
- 打包后的扩展能在 Chrome 中正常加载；这一步没有把网页内容发给后端。

目前按“**自动预览、手动加入、允许加入多段**”设计。你可以先看这份流程是否符合你的使用习惯，再决定是否调整。
