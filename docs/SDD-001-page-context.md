# SDD-001：读取网页正文，作为提问资料

> 2026-10-19 修订。单篇网页全文问答已接通，选区与正文预览已移除；范围开关和 @ 多资料已实现。资料选择见 SDD-005，任务执行见 SDD-002。

## 这一步要做什么

用户打开普通 HTML 技术文章，打开侧栏，就可以把文章作为参考资料提问，不再要求选中文字。读取的是浏览器已经加载的主要正文，不是整个网站，也不保证包含尚未加载的内容。

保留标题、网址、段落、标题层级和代码块，尽量保留列表与表格文字。排除导航、广告、脚本、输入框和隐藏内容。不做 PDF、视频、跨域 iframe、图片识别或自动滚动加载整页。

## 用户怎样操作

1. 打开侧栏，自动读取当前网页正文；只展示标题、网址和读取状态，不展示正文预览。可独立选择使用当前网页、搜索个人知识库或允许联网；默认使用网页与知识库，联网关闭。
2. 有权限时读取正文，只保留在扩展会话内。没有权限时显示“需要授权”，用户点击“授权并读取”。切页不自动弹权限窗口。
3. 读取成功后直接输入问题，不需要选中文字，也没有“使用这段”或正文确认步骤。动态页面可点击重新读取。也可通过 @ 添加其他已打开网页。
4. 点击“开始研究”才把问题与完整正文发给后端。仅打开侧栏、读取或切换网页，不发送研究请求，不自动保存笔记。

## 正文怎样提取

使用 Mozilla Readability 提取正文，并用 Turndown 及 GFM 表格插件转换结构；不再手写节点到文本的转换。Readability 在克隆的文档上工作，不修改原网页。提取后按标题、段落和代码块生成文本，解析时不执行网页脚本。普通技术文章是第一版验收范围，不保证所有网站都能提取。

提取失败可以重试，或由用户确认改用清理后的可见正文；降级时显示提示，不默默把导航菜单当成文章。动态网页内容加载后可以手动重新读取。

每份快照记录本地资料 ID、tabId、标题、网址、读取时间、正文、完整性及提取方式。读取前后核对目标网址，读取期间跳转则丢弃结果并提示重试。每次读取有独立请求编号，旧请求不能覆盖新页面。

## 全文怎样传给模型

不按三万字符截取或拒绝，完整主要正文直接提交。单篇超过 8 MiB UTF-8 传输容量时明确提示且不发送；这是本地资源限制，不是模型上下文声明。真实模型容量超限交由后端识别并提示。

按用户决定取消网页分段 RAG、意图分类和分层总结，见 [SDD-006](SDD-006-long-document-processing.md)。不增加正文预览、部分正文确认或选中文字步骤。个人知识库原有向量检索保留。

## 权限和状态

状态分为：正在加载、需要授权、正在读取、读取完成、超过传输容量、没有找到正文、不支持、读取失败。权限不足不能统一显示成“请打开普通网页”。

保留 activeTab、scripting。为列出其他标签页申请可选 tabs 权限，为读取所选站点声明 HTTP/HTTPS 可选站点权限。在用户点击添加或授权时申请需要的权限；拒绝后可移除附件，仍能只问知识库。

tabs 用于标题和网址等信息，不等于正文权限；activeTab 也不会自动授权其他标签页。站点权限按来源申请，不一开始要求读取所有网站。Chrome 内部页等受限页面即使授权也不能读取。

## 文件怎样分工（已建立）

    apps/extension/src/
      features/page-context/
        pageContext.types.ts        网页快照和读取状态
        extractPageContent.ts       在网页中提取主要正文
        pageContextApi.ts           调用浏览器读取能力，核对目标网址
        useCurrentPage.ts           维护“正在浏览”的页面信息
        CurrentPageCard.vue         当前页信息、授权与重读按钮
      background/index.ts           图标和标签页事件，不放提取算法

实际还增加 pageContentScript.ts，作为注入网页的独立构建入口，接收读取消息并调用提取函数。pageContextApi.ts 负责注入后发送请求；普通网页脚本不能直接导入侧栏里的 Vue 文件。

已删除 watchSelection.ts、useSelectionPreview.ts、SelectionPreview.vue，移除后台选区消息和监听。App.vue 统一持有网页状态，同时交给当前页卡片和提问组件，不重复读取。正文提取文件不负责模型请求。

## 完成后怎么检查

- 不选文字、不展开预览即可提问；提交给模型的正文包含文章结尾，代码缩进保留，原网页没被修改。
- 未授权、内部页、空正文、提取失败有不同提示，不显示旧页面资料。
- 切页后读取当前页；读取中跳转不串页，已经提交的任务继续使用原正文。@ 其他标签页支持独立授权、读取和重试。
- 超过旧三万字符限制的正文完整提交；真正超过传输或模型容量时明确提示，不丢弃后半部分。
- 仅读取不调用研究 API、不新增笔记。

## 当前接口

当前 POST /api/research/run 使用 question、materials 和 options，materials 包含 pages 与 noteIds。每篇网页包含 title、url、text、capturedAt、completeness，且 completeness 必须为 full。旧 context 单篇请求继续兼容，但不能和 materials 同时提供。旧 truncated 选区请求不再接受。后端 dto/research-input.dto.ts 统一检查完整性、长度和网址。

已取消三万字符校验，不再实施 SDD-006 旧稿的 Token 分流；当前以修订稿的全文直传为准。
