# SDD-001：读取网页正文，作为提问资料

> 2026-10-19 重新设计稿。替代旧版“选中文字、确认后提问”的流程。本文是待实现目标，代码目前仍使用选区。资料选择见 SDD-005，任务执行见 SDD-002。

## 这一步要做什么

用户打开普通 HTML 技术文章，打开侧栏，就可以把文章作为参考资料提问，不再要求选中文字。读取的是浏览器已经加载的主要正文，不是整个网站，也不保证包含尚未加载的内容。

保留标题、网址、段落、标题层级和代码块，尽量保留列表与表格文字。排除导航、广告、脚本、输入框和隐藏内容。不做 PDF、视频、跨域 iframe、图片识别或自动滚动加载整页。

## 用户怎样操作

1. 打开侧栏，显示“正在浏览”的网页标题和网址。第一次进入空草稿时将当前页加入本次资料，默认开启知识库搜索，默认关闭联网。
2. 有权限时读取正文，只保留在扩展会话内。没有权限时显示“需要授权”，用户点击“授权并读取”。切页不自动弹权限窗口。
3. 资料卡片显示标题、读取状态、正文长度及可展开预览，可以移除或重新读取，也可以通过 @ 添加其他已打开网页。
4. 点击“开始研究”才把问题与选中的正文发给后端。仅打开侧栏、读取或切换网页，不发送研究请求，不自动保存笔记。

## 正文怎样提取

优先采用 Mozilla Readability 等成熟正文提取库，在克隆的文档上工作，不修改原网页。提取后按标题、段落和代码块生成文本，解析时不执行网页脚本。普通技术文章是第一版验收范围，不保证所有网站都能提取。

提取失败可以重试，或由用户确认改用清理后的可见正文；降级时显示提示，不默默把导航菜单当成文章。动态网页内容加载后可以手动重新读取。

每份快照记录本地资料 ID、tabId、标题、网址、读取时间、正文、完整性及提取方式。读取前后核对目标网址，读取期间跳转则丢弃结果并提示重试。每次读取有独立请求编号，旧请求不能覆盖新页面。

## 长文章怎样处理

初始限制：单篇最多 30,000 字符，最多 3 篇网页，正文合计最多 60,000 字符。这是产品限制，不是模型容量保证；后端还要为笔记、工具结果、问题和回答保留 token 预算，并限制请求体大小。

超出限制显示“文章过长，尚未完整加入”，不悄悄发送开头并声称完整。用户可以移除、换较短资料，或明确确认仅使用预览中的部分正文。未确认的截取结果不能提交；确认后持续标注“仅使用部分正文”。

后续再做长文切段、按问题检索相关段落，本轮不以它为前置条件，也不把临时网页分段自动存入知识库。

## 权限和状态

状态分为：正在加载、需要授权、正在读取、读取完成、仅有部分正文、没有找到正文、不支持、读取失败。权限不足不能统一显示成“请打开普通网页”。

保留 activeTab、scripting。为列出其他标签页申请可选 tabs 权限，为读取所选站点声明 HTTP/HTTPS 可选站点权限。在用户点击添加或授权时申请需要的权限；拒绝后可移除附件，仍能只问知识库。

tabs 用于标题和网址等信息，不等于正文权限；activeTab 也不会自动授权其他标签页。站点权限按来源申请，不一开始要求读取所有网站。Chrome 内部页等受限页面即使授权也不能读取。

旧 watchSelection.ts、useSelectionPreview.ts、SelectionPreview.vue 在新流程连通后一起移除，清理旧选区存储键。不先删旧入口导致无法演示。资料清单和任务状态不放进提取文件。

## 完成后怎么检查

- 不选文字也能读取技术文章，标题、段落和代码可读，原网页没被修改。
- 未授权、内部页、空正文、提取失败有不同提示，不显示旧页面资料。
- 其他标签页取得正确正文；读取中跳转不串页。
- 长文不会在没有提示时丢失后半部分。
- 仅读取不调用研究 API、不新增笔记。
