# SDD-002：一次提问任务怎样执行

> 2026-10-15 更新。对应 PRD 的 F3—F6。先有 SDD-001 的已确认选区，再开始本任务；知识库的保存与管理见 SDD-003。文中包含目标流程，当前代码仍在逐步实现。

## 这次任务是什么

用户对当前技术网页中**已确认的一段文字**提出一个问题，例如“这段 TypeScript 说明中的类型收窄是什么意思？”侧栏展示任务真实走到哪一步，最后逐步给出解释和当前网页来源。

一条问题就是一条任务。用户更换选区或再次提问时，新建任务，不把两次结果混在一起。

## 从点击“开始”到得到回答

1. 侧栏检查：有已确认选区、问题不为空、标题和网址属于当前标签页。缺一项就提示用户，不创建任务。
2. 侧栏把问题和已确认的标题、网址、选区发给本地 NestJS。后端给这次运行分配任务 ID，记录“开始”。
3. 后端每次执行 **read_current_context** 和 **search_knowledge_base**。知识库检索同时参考用户问题和本次选区；没有相关笔记时返回空列表。这两步是固定任务流程，不声称由 Qwen 自主选择。
4. Qwen 看过现有资料后，可以决定是否调用 **web_search** 查找最新资料；有值得核对的搜索结果时，可以进一步调用 **read_web_page**。后端检查工具名、参数和次数，实际执行后再把结果交回 Qwen。每种联网工具最多调用一次，不允许读取搜索结果之外的任意网址。
5. Qwen 根据取得的资料生成回答。后端把新生成的文字逐段送到侧栏；只在工具真正执行时记录“开始、完成或失败”。
6. 成功时显示“已完成”；回答旁按当前选区、个人笔记、联网资料展示可点击的来源。若资料不能支持回答，明确说明信息不足。完成后用户可以选择整理并保存，见 SDD-003。

当前选区必须成功读取，才能把回答标为基于当前网页。知识库每次搜索，查不到就返回空结果；搜索失败时如实说明。联网工具是可选的，模型没有成功调用时不能显示“已联网核对”。工具不会让模型执行代码或自行保存资料。

## 用户会看到哪些状态

| 状态 | 什么时候出现 |
| --- | --- |
| 已开始 | 后端确实创建了任务 |
| 正在读取选区 | 后端收到本次已确认的选区，准备执行读取工具 |
| 选区读取完成／失败 | 工具已经返回结果 |
| 正在查找旧笔记、查找完成／失败 | 知识库工具确实执行时才出现 |
| 正在联网查找、已找到来源／失败 | 联网搜索真正执行时才出现 |
| 正在阅读网页、阅读完成／失败 | 网页阅读工具真正执行时才出现 |
| 正在生成回答 | Qwen 开始产生回答文字 |
| 已完成／已停止／失败 | 任务进入最终状态 |

进度来自后端发生过的事件。界面可以用通俗文字展示，但不能把固定动画或猜测的步骤当成真实调用记录。模型内部推理文本不显示。

## 回答旁怎样查看来源

来源分成三类卡片：

- **当前选区**：显示本次确认的原文、网页标题和网址；点击可查看原文并打开原网页。
- **个人笔记**：显示笔记标题和实际检索到的内容；点击可展开笔记，并打开保存时记录的原网页。
- **联网资料**：只展示联网工具实际返回的网址和标题；点击打开该网页。若进一步阅读过网页，可同时展示阅读到的片段。

普通网页不一定有稳定的段落地址，因此第一版不保证打开后自动定位到原句；卡片内始终保留可核对的文字。检索到了资料不代表回答一定引用它。界面用“参考资料”列出实际提供给模型的内容；只有回答中的来源标记能匹配到真实来源 ID 时，才显示“已引用”。不能把模型自行写出的链接当作来源。

## 怎样传输和停止

第一版用一次请求启动任务并持续接收事件：侧栏向本地 API 发起请求，后端以流式事件返回任务 ID、进度、回答片段和最终状态。侧栏用当前任务 ID 接收这些片段。

点击“停止”时，侧栏中断这次请求；后端同时停止继续调用模型，并把任务记为“已停止”。任务进行中若切换标签页或当前页跳转，也按停止处理，并清除旧页面选区。旧任务迟到的片段不能追加到新任务的回答。网络断开或后端重启时，侧栏显示失败，不一直停在“生成中”。

“重试”会用同一个问题和仍然有效的已确认选区**创建新任务**，保留原任务的失败状态，不把两次输出拼起来。

## 数据放在哪里

- 扩展会话存储保留当前页的预览与已确认选区。
- NestJS 在任务执行期间临时持有选区全文，供 read_current_context 读取；任务结束后释放。
- PostgreSQL 保存任务 ID、问题、状态、时间，以及真实的工具和状态事件；另外保存用户确认过的知识条目。普通提问不把选区全文、模型密钥或每个回答文字片段写入数据库。
- Qwen API Key 只放在后端环境变量；扩展中没有密钥。

知识条目的字段、向量生成和保存时机见 SDD-003。向量只保存在知识条目中，不给每次提问永久保存一份问题向量。

## 代码准备怎样放

    apps/extension/src/
      features/page-context/       选区预览与确认
      features/research-run/        问题输入、进度、流式回答、停止与重试
      background/                   浏览器图标和标签页事件

    apps/api/src/
      research/                     创建和运行任务、发送事件、记录状态
        tools/                      当前选区、知识库、联网搜索与网页阅读工具
      knowledge/                    知识条目保存、管理和向量查找

目录按功能分开即可。第一版不建通用 Agent 框架、工具插件系统或多 Agent 调度层。

## 失败时怎么处理

- 没有已确认选区、切换了标签页：侧栏阻止提交，并提示重新选取。
- 当前页不允许读取：沿用 SDD-001 的页面提示。
- 工具调用失败、Qwen 报错或超时：记录任务失败，显示能看懂的原因和“重试”。
- 用户主动停止：显示“已停止”，不再展示后来到达的回答片段。
- 知识库搜索失败：显示真实失败状态；若当前选区已经读取成功，可以说明旧笔记暂时不可用，继续基于当前选区回答。
- 选区证据不足：正常结束任务，但回答明确说明不足；不补造网页内容或来源。

## 做完后怎么检查

用一篇固定的公开技术文章演示：确认选区、发起任务、看到真实工具记录、逐步生成的回答和当前页来源；保存一条笔记，再问相关问题并看到真实的知识库搜索结果。另测试停止、模型出错和切换标签页。演示记录中的工具步骤必须能在后端实际执行事件中找到。
